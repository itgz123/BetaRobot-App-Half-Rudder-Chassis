#### 超电逻辑

| 字段                           | 值       | 备注                           |
| ---------------------------- | ------- | ---------------------------- |
| enable_dcdc                  | 1       | 开启超电充电                       |
| clear_error                  | 1       | 清理可以清理的错误                    |
| enable_active_charging_limit | 1       | 使能充电上限                       |
| active_charging_limit_ratio  | 255     | 设置上限00%                      |
| referee_power_limit          | 当前功率上限  | 把裁判系统当前功率上限发送过去，直接透传或者根据等级查表 |
| referee_energy_buffer        | 当前能量缓冲区 | 直接透传裁判系统能量缓冲区大小              |
